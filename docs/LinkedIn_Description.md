🎧 **New Project: Customer Support Ticket Analysis**

I recently built an end-to-end data analytics project analyzing 12,000+
customer support tickets — the kind of dataset a real support operations
team at a company like Amazon, TCS, or Accenture would work with daily.

**What I did:**
🔹 Cleaned and preprocessed a realistic, messy ticket dataset (duplicates,
missing values, type issues) using Python & Pandas
🔹 Performed exploratory data analysis to uncover ticket volume trends,
category breakdowns, and priority/escalation patterns
🔹 Calculated core support KPIs: SLA compliance, average resolution time,
CSAT, and escalation rate
🔹 Built an agent performance scorecard to compare resolution speed and
customer satisfaction across a 15-person support team
🔹 Wrote 12 SQL queries replicating the analysis for a data-warehouse
context (agent performance, regional CSAT, high-priority unresolved tickets)
🔹 Designed a Power BI dashboard with KPI cards, trend charts, and
interactive slicers for executive reporting

**Key insight:** Overall SLA compliance sat at ~80%, with Critical-priority
tickets driving the majority of breaches and escalations — a clear signal
for where a fast-lane triage process would have the biggest business impact.

This project reflects the kind of analysis I'd want to bring to a real
support/operations analytics role: not just building charts, but tying the
numbers back to concrete business recommendations.
