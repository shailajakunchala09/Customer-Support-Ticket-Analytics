**Customer Support Ticket Analysis** | Python, Pandas, SQL, Power BI | [GitHub Link]

- Built an end-to-end analytics pipeline analyzing 12,000+ customer support
  tickets to evaluate resolution efficiency, SLA compliance, and customer
  satisfaction, uncovering a 20% SLA breach rate concentrated in high-priority tickets.
- Designed and implemented a modular Python data-cleaning pipeline (Pandas,
  NumPy) handling duplicate records, missing values, and type standardization
  across 12,000+ rows with full logging and exception handling.
- Authored 12 production-style SQL queries covering agent performance, SLA
  compliance, regional CSAT, and escalation analysis for a relational
  data-warehouse layer.
- Designed a Power BI dashboard (KPI cards, trend charts, regional maps,
  agent scorecards) with DAX measures and interactive slicers to support
  executive-level reporting.
- Delivered a written business report translating analytical findings into
  6 prioritized, actionable recommendations to reduce ticket volume and
  improve SLA compliance.
